# Security policy

This repository contains only documentation (Markdown and JSON) for using the QR Suisse public API.

To report a vulnerability in QR Suisse or in this content, do not open a public issue. Use GitHub's
"Report a vulnerability" button (Security tab of this repository) or write to contact@qrsuisse.ch
with the subject "Security".

If you have exposed a QR Suisse API key, rotate or revoke it immediately from the QR Suisse
dashboard. Never send an API key in a report.
